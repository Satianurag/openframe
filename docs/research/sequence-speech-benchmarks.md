# Sequence speech and captions — evidence checked29 October2026

This selection is for explicit narration and editable subtitles inside video sequences. It is not a standalone voice product, a universal quality ranking, or a claim of tested OpenFrame output. Implementation is being completed before runtime validation; no model weights were downloaded during this research.

| Released candidate | Relevant primary evidence | License / implementation consequence |
| --- | --- | --- |

These measure different settings and ranks change. | [MIT model](https://huggingface.co/inclusionAI/Ming-3.0-tts-0.5b). Ming's own SeedTTS comparison lists Qwen1.7BBase with lower Chinese/English WER than Ming0.5B; this contradicts any claim that Ming wins every metric. | [Released Apache2 code/weights](https://github.com/QwenLM/Qwen3-TTS). Strong alternative, especially broader built-in multilingual/voice-design requirements; not silently substituted into this implementation. |

No same-script OpenFrame comparison has been performed. |
| Qwen3-ASR1.7B + ForcedAligner0.6B | [Official source](https://github.com/QwenLM/Qwen3-ASR) and [report](https://arxiv.org/abs/2601.21337) provide recognition and an explicit word/character alignment API. Recognition and alignment have different language coverage; this integration deliberately exposes English/Chinese. | Apache2. Selected for actual recognized text plus supported alignment, rather than fabricated evenly spaced words or aligning an unchecked script as if it had been spoken. |
| GraniteSpeech5.0, October20/21 refresh | [IBM's2B card](https://huggingface.co/ibm-granite/granite-speech-5.0-2b) evaluates current multilingual recognition, punctuation and capitalization. Particularly credible for throughput/edge use. Different aggregate benchmark snapshots must not be mixed into a fake single leaderboard; Qwen remains selected here for the complete recognition+alignment contract. |

Primary benchmark distinctions: [Artificial Analysis ControlledVoice](https://artificialanalysis.ai/text-to-speech/leaderboard/controlled-voice) controls reference voices; [ProviderVoice](https://artificialanalysis.ai/text-to-speech/leaderboard/provider-voice) evaluates supplied voices. Preference, pronunciation, WER, speaker similarity, latency and language coverage answer different questions. No evidence here establishes one model as best for every narration job.

## Pinned runtime and honest boundaries

- Ming code `9332fb9443325d4726ce02cefd4ec1c211df4079`; model `7247f4c94a5b2e987404ed28a5cfec41b1a4ca61`. Built-in English US/UK and Chinese voices; no reference-voice cloning is implied. The0.5B label describes the released model variant, not a promise of a0.5GB package: its main safetensors file is2,959,055,504bytes.
- Qwen ASR code `7c6daf77a2421100f5fb066495372c00129d39ff`; ASR weights `7278e1e70fe206f11671096ffdd38061171dd6e5`; aligner `c7cbfc2048c462b0d63a45797104fc9db3ad62b7`. Expected upstream LFS hashes and sizes are recorded in `engine/narration_models.py`; fetching metadata is not byte verification.
- Separate remote environments preserve Ming's Torch2.6/Transformers4.46.3 stack and Qwen's Transformers4.57.6 without downgrading ComfyUI. Built-in-voice synthesis runs first; its process exits before recognition/alignment. Heavy work and weights stay on the configured Linux CUDA ComfyUI host; see the bundled narration runtime guide.
- Production text normalization and sentence splitting differ from Ming's documented raw-text benchmark mode. Optional speed is explicit FFmpeg tempo processing before recognition. Measured speech must fit its reviewed shot interval; the app does not clip speech, invent timing, loop music, or call a partially failed episode complete.
