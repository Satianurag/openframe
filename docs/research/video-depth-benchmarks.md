## Implemented source contract

`video-depth-small` and `vigeo-1.1` share task/effect `video-depth`. Source FPS and aspect are retained. The requested interval is explicit:2–300frames, even dimensions, at most1280pixels on the long side and921600pixels total. Defaults fit the source within a768pixel long side without upscaling. Unsupported intervals fail instead of silently truncating. This is a bounded product envelope, not a claim that a model's research maximum is300frames.

The node produces a near-white grayscale viewing MP4 and a separate lossless FFV1 gray16 MKV. One global min/max pair maps all valid predictions into codes1–65535;0 is invalid. `metadata.depth` records raw semantics, inference parameters and the inverse mapping. VDA values are relative inverse depth; ViGeo values are relative depth. Preview polarity is unified, but raw meanings are not concealed. Optional original audio belongs only to the preview.

All inference is CUDA/cache-only; the public app defaults to configured Local ComfyUI. Pinned manifests include expected upstream hashes, not a claim that local bytes were verified. VDA source `4f5ae23172ba60fd7bc11ef671cca678842c7072` uses its released116,440,756-byte Small checkpoint. ViGeo source `1b2a48324759f34c323358084f7d60a9c5fbf2a7` uses the released5,054,751,381-byte1.1 checkpoint. Exact weight revisions and hashes are in `engine/depth_models.py`.

The VDA import adaptation only relocates its upstream alignment helper into its own package namespace, avoiding ComfyUI's unrelated `utils` module. It changes no temporal algorithm. Original source/license files remain in the pinned checkout. No upstream legacy Torch/xformers pins are installed over ComfyUI.
