## Shared desktop behavior

The reviewed flows include actual media playback, explicit source-range selection, saved draft reload, immutable recipe reuse, cancelled-job retry, scoped app history, prompt/seed/model restoration, real downloads, caption correction and native ComfyUI canvas import/export. Requested durations beyond remaining source/model bounds are rejected; valid native frame-lattice quantization is shown rather than silently presented as full source coverage.

The application contains10 main functional workspaces and29 tool/effect detail pages. The Effects listing is a separate navigation hub, not another independently validated generator. Legacy Canvas/Supercomputer/Speak redirects are excluded from the functional page count. This inventory is not39 quality certifications.

## Public execution boundaries

Local ComfyUI requires the selected model/node/runtime installation on the configured GPU host. Heavy runtime checks used controlled Linux CUDA hosts, not every independent PC platform. Direct Comfy Cloud only exposes supported model/task combinations. Historical LTX2.3 hosted inference exists; the current LTX2.5 inpaint adapter has catalogue/schema/CPU/export checks, not a new live hosted acceptance run.
