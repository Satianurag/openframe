# Video implementation selected on 29 October 2026

This document records the implementation recipes, not a blanket runtime or quality pass. The initial source-only gate has passed; current scoped runs, failures and remaining checks are recorded in [DESKTOP-VALIDATION.md](DESKTOP-VALIDATION.md). Prior model versions retain separate evidence. See [the sourced model comparison](research/video-model-benchmarks.md) for selection evidence and its limits.

Public execution uses a configured capable Local ComfyUI host; model files and heavy inference stay on that host, which may be separate from the lightweight interface/backend computer. Hosted Comfy Cloud support is model/task-specific: the current LTX2.5 adapter supports inpainting, with explicit app preparation and optional finishing, not every operation below. Check catalogue provider capabilities and [API.md](API.md#native-ltx25-hosted-inpaint-boundary). Recorded private GPU tests do not establish independent Local installation or untested Cloud execution.

## LTX operation contracts

- Generation uses the official distilled eight-step schedule. Optional two-stage refinement uses the published latent spatial upscaler and three-step refinement. The optional prompt enhancer uses its own Gemma 4 E2B checkpoint and is recorded in the graph.
- Masked inpainting and spatial outpainting use the exact **2.3-named IC-LoRA 0.9** explicitly connected in the official **2.5 templates**. The filename is intentional. Two-stage masked refinement decodes, blends, pixel-upscales and re-encodes before its two-step pass. It retains OpenFrame's original-plate preservation and contour treatment; green conditioning placeholders are never used as a compositing plate.
- Spatial outpaint places the source on a larger canvas. Scale and anchors control the placement. A same-sized filled canvas is rejected instead of pretending to generate new area.
- Temporal Extend uses native `LTXVAddGuide` video-context tokens, not the spatial outpaint adapter. `context_frames` selects the actual source prefix from `trim_start`; total `frames` includes that context plus new footage. Sequel anchors/restores the context at the start; Prequel anchors/restores it at the tail. The prequel graph handles the native VAE's causal first-frame token separately, then guides the remaining context at its actual temporal position. Context audio follows that placement, with generated audio or silence elsewhere. Neither direction silently includes an entire longer original video.
- Transition uses two real media endpoints, native guide positions `0` and `-1`, and explicit endpoint restoration. An optional still-image midpoint guide uses native frame 60/120 for 121/241-frame clips, at strength 1 in both sampling stages. It shares endpoint framing and refinement padding; its file/fitted-image hashes, frame, time and canvas are recorded. The midpoint is conditioning, not a pasted or pixel-restored frame. Existing two-input requests are unchanged. At 24 fps the bridges last 5.04/10.04 seconds; optional original-clip assembly is separate from generation.
- Pixel 2× upscale uses its dedicated adapter at reference-downscale factor 2. Input is padded without stretching, inference dimensions are padded to 32, and output is cropped to exactly twice the original dimensions. This is a **creative generative upscaler**, not a guaranteed faithful restoration filter.
- Tiled refinement uses the distinct Refine Details adapter and official overlapping Tiled Fusion sampler. Its requested canvas is explicit; it does not pretend to be the same algorithm as Pixel 2×.
- AlphaGen always receives an empty prompt, runs only its native first stage, and uses no object-selection mask. It pads original RGB without stretching and crops the generated matte back to the original dimensions. A transparent VP9 WebM combines the matte with **original RGB**, plus a separate grayscale matte. Its model card limits this path to 145 frames and 1920×1088-equivalent dimensions.
- Clean Plate uses its dedicated adapter for full-frame people/dynamic-foreground removal. The prompt describes the desired empty environment. This is not a substitute for user-selected masked object removal, and it can fail when insufficient background is visible.
- SDR-to-HDR uses the published scene embedding and adapter, sRGB→ACEScct input, and native color conversion. Explicit outputs are HEVC 10-bit or ProRes 422 HQ 10-bit in BT.2020/HLG, or an opt-in ZIP of scene-linear ACEScg half-float EXRs with chromaticity metadata. The dedicated saver streams high-bit-depth data; it never derives these formats from an 8-bit preview. A separate SDR preview supports ordinary browser playback. Video exports can retain source audio; an EXR image archive has no muxed audio. Current profile bounds are 145 frames, 1920×1088 in either orientation and a 4 GiB raw EXR estimate.

## Compatibility fixes made before execution

The old wrapper LongCat example is Avatar 1.0/Wav2Vec2. Version 1.5 uses Whisper features at stride 1 and 25 fps. Its official pipeline also changes the distilled schedule from a 50-point selection to its own eight-point grid; the published scheduler config has shift 7. `OpenFrameLongCat15Scheduler` implements that exact path. Reusing the wrapper's `longcat_distill_euler` with shift 12 would have been a version mismatch.

The wrapper's older T5 loader rejects scaled FP8 UMT5. The new graph uses the wrapper's published conditioning bridge from native Comfy CLIP instead, reusing the existing encoder rather than downloading an unnecessary duplicate.

Model manifests record immutable revisions, byte sizes and known SHA-256 values. Runtime requirements are filtered by actual task, prompt-enhancement switch and upscale mode. Downloads happen only in the explicit preparation step; missing weights fail preflight. Multiple LTX repositories are individually gated, and access to the older inpainting adapter does not grant access to every 2.5 repository.

The planned post-implementation verification must cover actual node catalogs, task input validation, complete rendered clips, original-region preservation, audio timing, genuine alpha/HDR stream metadata, motion fidelity and lip synchronization. Source completeness alone is not a quality pass.

Prompt-selected background removal is a separate [SAM3.1 → trimap → ViTMatte profile](SEMANTIC-MATTING.md). It does not route unsupported subject text into AlphaGen. [Character training](CHARACTER-TRAINING.md) likewise uses the separately pinned undistilled FLUX3 base; it does not relabel reference conditioning as training.
